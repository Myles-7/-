# PromptVault 本地提示词工坊 — 进阶体验与效率优化方案

本次升级聚焦于**提升高频复用效率**与**大规模提示词库的批量治理能力**，在不增加界面冗余复杂度的前提下，落地「枚举下拉变量 + 多套参数预设」「分类重命名排序 + 多选批处理」以及「可复用公共提示词片段（Snippets）」三大核心能力。

---

## 用户确认与关键决策

> [!IMPORTANT]
> 以下为第一阶段交互确认的核心优化范围，将在本方案批准后完整实现：

- **确认决策 1（动态变量升级）**：支持在模板中使用 `{{变量名:选项A|选项B|选项C}}` 语法直接渲染为快捷下拉/胶囊选择器，并支持为单条提示词保存多套「命名参数预设方案（Variable Presets）」，一键切换整组变量值。
- **确认决策 2（分类治理与批量操作）**：左侧两级分类树支持**双击原地重命名**与**上下调整排序**；主视图新增轻量「批量整理模式」，支持多选提示词后一键批量迁移一级/二级分类、批量打标签、批量导出与批量删除。
- **确认决策 3（可复用公共片段库 Snippets）**：在编辑器与快速迭代面板中集成「公共片段与约束块」，支持一键向光标处插入常用角色设定、输出格式约束（如去 AI 腔、Markdown 表格、严格 JSON 等），并支持自定义新建与管理个人片段。

## 1. 核心概念与价值概览

- **核心能力**：将原本静态的提示词模板升级为「可配置参数的模块化工作流」，同时赋予用户对成百上千条提示词进行秒级归档、改名与重排的治理工具。
- **适用场景**：
  - 同一条提示词需要在不同项目/语境下切换整套变量参数（如不同技术栈、不同目标受众、不同输出语气）；
  - 外部导入大量提示词后，需要快速勾选几十条提示词统一划入新建的二级子分类或统一打上标签；
  - 编写新提示词时，无需重复手写“请避免套话、使用 Markdown 表格输出”等通用尾缀约束。

## 2. 用户体验与视觉设计

### 核心交互流程
1. **枚举变量与多套参数预设流**：
   - 当提示词中包含 `{{输出语气:专业严谨|通俗易懂|精炼毒舌}}` 时，右侧工作台自动将该变量识别为**枚举型变量**，提供一键点选胶囊/下拉框，同时保留手动输入自定义值的灵活性。
   - 工作台变量区顶部新增「参数预设」切换条：用户填好一组变量后点击「+ 存为预设」输入名称（如 `React 19 生产环境`），即可生成预设标签，后续点击即可瞬间回填整套变量。
2. **两级分类原地重命名与排序流**：
   - 在左侧分类树中，双击任意一级分类或二级子分类名称（或点击悬停操作图标）即可原地编辑名称，回车即刻生效。
   - 悬停分类项时提供精巧的上移/下移微调按钮，方便将最常用的一级大类与二级子分类排在顺手位置。
3. **多选批量整理流**：
   - 点击工具栏右侧的「批量整理」按钮进入多选模式，卡片与列表行左上角浮现勾选框，顶部可一键「全选当前筛选结果」。
   - 选中至少 1 条提示词后，底部浮现深色高对比度**批量操作浮动栏**：支持「批量移动至分类（含二级子分类）」「批量添加标签」「批量导出 JSON/MD」「批量删除」。
4. **公共提示词片段（Snippets）插入流**：
   - 在「新建/编辑提示词弹窗」与右侧工作台「直接修改迭代」的工具栏上，点击「插入公共片段」即可展开片段浮层，点击任意片段自动插入到文本框当前光标处，并支持将选中的常用段落保存为新片段。

### 视觉与排版规范
- **设计风格**：延续大气清爽的瑞士网格与编辑部留白（Editorial Daylight），保持零冗余胶囊（Zero-Pill Discipline）与清晰层级。
- **色彩规范**：
  - 画布背景：`#F8FAFC`（`bg-slate-50`），卡片与面板容器：`#FFFFFF`（`bg-white`）配合 `1px solid #E2E8F0`；
  - 交互高亮与主色：`#2563EB`（`blue-600`），主操作按钮：`#0F172A`（`slate-900`）；
  - 枚举变量与预设指示：采用柔和蓝底色 `#EFF6FF` 与等宽字体 `JetBrains Mono`。
- **动效反馈**：批量操作浮动栏、公共片段抽屉及卡片勾选状态均采用 `180ms cubic-bezier(0.16, 1, 0.3, 1)` 硬件加速过渡。

## 3. 关键产品决策与权衡

- **决策 1：内联枚举变量语法设计 (`{{变量名:选项1|选项2}}`)**
  - *方案选择*：采用向后兼容的冒号+竖线语法 `{{变量名:选项A|选项B}}`，在卡片预览与正文中仅高亮显示 깔끔的 `{{变量名}}` 或当前选中值，不暴露冗长选项字符串。
  - *原因*：既能让用户在纯文本编辑和 Markdown 导入导出时一眼看懂并随手编写，又不会破坏原有 `{{变量名}}` 的简洁性。
- **决策 2：按需开启的「批量整理模式」**
  - *方案选择*：默认保持纯净的点击即用视图，仅当点击工具栏「批量整理」时才展示复选框与底部批处理栏。
  - *原因*：避免日常高频查阅复制时满屏复选框造成的视觉干扰，做到“用时极简、管时高效”。

### 数据模型扩展
1. **枚举变量描述符 (`PromptVariableDescriptor`)**：
   - 从模板正文自动解析出 `{ name: string, options?: string[], rawToken: string }`，兼容普通变量与枚举选项变量。
2. **多套变量预设 (`VariablePreset`)**：
   - 在 `PromptItem` 中新增可选字段 `variablePresets?: { id: string; name: string; values: Record<string, string> }[]`。
3. **公共提示词片段 (`PromptSnippet`)**：
   - `{ id: string; title: string; category: '角色设定' | '输出格式' | '思维链与约束' | '自定义'; content: string }`，持久化于 `promptvault_snippets_v2`，并预置 6 条实用精选片段。

### 交互状态映射
- **分类重命名与排序**：修改分类名称或顺序时，直接更新 `categories` 数组顺序与节点 `name`，由于 `PromptItem` 通过稳定的 `categoryId` 与 `subCategoryId` 关联，重命名与排序零副作用且实时同步至卡片面包屑与顶部快筛栏。
- **批量操作执行**：勾选集合存储在 `selectedPromptIds: Set<string>`；执行批量移动分类、批量加标签或批量删除后，自动显示带操作计数与撤销支持的底部 Toast 通知。
